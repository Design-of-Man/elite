brought in. This is the number that answers "is it working", so it gets counted
the same way every month. Counts only: no names, phones or reasons for the visit.

## How to count

**Web appointment requests.** Gmail (nicholasbkashuba@gmail.com), search:

```
from:submissions@formsubmit.co subject:"elitesportsmed.org"
```

Each one is also copied to info@elitesportsmed.org and matarazzomd@gmail.com.
Count one per real submission. Leave out:

- the FormSubmit activation email;
- tests (a name or subject with TEST, or nicholasbkashuba@ as the sender's email);
- Dr. Matarazzo's own submissions;
- anything FormSubmit marks `[Possible spam]` that is a sales pitch.

Before 2026-09-20 the old site's form left no record we can count, so there is no
earlier web baseline. Don't fill those cells with zero.

profiles (Windsor, `google_my_business`, fields `call_clicks` and
`direction_requests`):

- Port St. Lucie: `locations/8689948599312691435`
- Palm Beach Gardens: `locations/13510812082515088638` (no data before 2026-09-15)

Google's numbers lag 2–3 days. Count a month once it has closed and the last
days have filled in.
